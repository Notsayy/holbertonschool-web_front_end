# Cookies and Web Storage Project

## Description

This project demonstrates how to manage cookies and browser web storage (localStorage and sessionStorage) using JavaScript. Through a series of HTML files, you will learn how to create, read, and manipulate cookies, as well as how to use the browser's web storage APIs to store and retrieve data. The project also introduces the use of the js-cookie library for easier cookie management and implements a simple cart system as a practical example.

## Learning Objectives

- Understand how to create cookies using JavaScript
- Learn how to set specific settings for cookies (expiration, path, etc.)
- Learn how to read cookies with JavaScript
- Use the js-cookie library for easy cookie manipulation
- Use the browser web storage (localStorage and sessionStorage)
- Understand the differences between local storage and session storage

## Project Structure

- `0-index.html` to `7-index.html`: Each file demonstrates a different aspect of cookies or web storage, progressing from basic cookie creation to an advanced cart system using sessionStorage.
- `src/index.js`: This file must remain empty. All JavaScript code is written directly inside the `<script>` tags in each HTML file.
- `package.json`: Project configuration and dependencies.
- `README.md`: Project documentation (this file).

## Requirements

- Allowed editors: vi, vim, emacs, Visual Studio Code
- All files should end with a new line
- A `README.md` file at the root of the project is mandatory
- All code should use the `.js` extension
- All code will be compiled/executed on Ubuntu 20.04 LTC using Node 20.x.x and npm 10.x.x
- `src/index.js` must stay empty; all JavaScript must be in the HTML files inside `<script>` tags

## Usage

1. Open any of the `*-index.html` files in your browser to see the corresponding feature in action.
2. Review the JavaScript code inside each HTML file to understand how cookies and web storage are managed.
3. For the advanced cart system, open `7-index.html` and interact with the product list and cart.

## Notable Features

- Cookie creation, reading, and deletion
- Setting cookie attributes (expiration, path)
- Using js-cookie for simplified cookie handling
- Using localStorage and sessionStorage for persistent and session-based data
- Implementing a shopping cart using sessionStorage
